## 📌 Executive Summary

**CreatorPulse AI** is a specialized pre-publication intelligence and decision-support system built for YouTube creators, media strategists, and digital marketers. 

While generic conversational LLMs generate long, poetic titles without considering platform-level viewport truncation or viral CTR mechanics, **CreatorPulse AI** evaluates title syntax, mobile feed safety (45–65 character sweet spot), power-word weight distributions, and curiosity gap anchors. It features mathematical reach spline forecasting, live YouTube video auditing via dual oEmbed gateways, and real-time multi-archetype viral title synthesis.

---

## 🌟 Key Features

1. **Behavioral NLP Title Evaluation:**
   - **Mobile Feed Sweet Spot:** Enforces 45–65 character optimization to prevent title truncation on mobile feeds.
   - **Lexical Power-Word Weighing:** Scores urgency, high-stakes curiosity, and contrarian hook phrases.
   - **Syntactic Modulation:** Calibrates uppercase ratios, numeric anchors, and question constructs.

2. **Live YouTube Video & Channel Auditing:**
   - Universal URL parser supporting standard `watch?v=`, `youtu.be`, `/shorts/`, and channel search queries.
   - Dual-gateway fallback (Official YouTube oEmbed + Noembed gateway) pulling live video titles, channel authors, thumbnails, and verified audience tiers.

3. **Algorithmic Velocity & Reach Forecasting:**
   - Models an interactive 24-hour polynomial reach spline.
   - Computes dynamic Click-Through Rate (CTR%) and Average View Duration (AVD) based on title linguistics.

4. **Dynamic Title Generation (Like ChatGPT):**
   - Real-time debounced typing generation (350ms delay).
   - "✧ Generate Titles" and "↻ More Ideas" buttons rotating across 12+ viral archetypes (*24-Hour Sprints, Contrarian Truths, Fatal Mistakes, Industry Shifts, Zero-to-Hero Blueprints*).
   - Built-in **"Copy"** (with feedback) and **"Use ↵"** one-click dashboard application buttons.

5. **Mobile Viewport Simulation:**
   - Live 16:9 YouTube app card simulation allowing creators to inspect how their title will display to mobile users before publishing.

## 🚀 Quickstart & Installation

### Option 1: Run Locally in Browser
No build tools or server installation required:
```bash
# 1. Clone this repository
git clone https://github.com/your-username/creatorpulse-ai.git

# 2. Open the folder
cd creatorpulse-ai

# 3. Launch index.html in any modern browser
# (Double-click index.html or open via VS Code Live Server)
```

### Option 2: Run Python ML Engine
```bash
cd python_engine
python pulse_engine.py
```

### Option 3: Deploy to Vercel (Recommended)
This repository is configured for instantaneous deployment on Vercel:
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
3. Import your `creatorpulse-ai` repo and click **Deploy**.
4. Your application will be live globally in ~15 seconds with SSL!
